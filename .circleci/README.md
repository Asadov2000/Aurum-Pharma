# CircleCI Free: пробный запуск

Этот workflow проверяет доступность Linux и Windows в новом аккаунте CircleCI.
Он **не заменяет обязательный GitHub `CI gate`** и не подтверждает прохождение
полной матрицы проверок приложения. Защита `main` остаётся прежней.

- Запуск только из `codex/circleci-free-pilot`.
- Linux: существующие 7 тестов проверки полноты backend shard-отчётов.
- Windows: существующие проверки CORS, broker rollout и Edge identity wrapper
  с синтетическими данными и подставными командами.
- Windows запускается только после успешного Linux, чтобы не расходовать
  кредиты при ошибке начальной настройки.
- Нет расписаний, деплоя, рабочих секретов, кэшей и загрузки артефактов.
- Используется Free без карты, покупки кредитов или платного пробного периода.

После запуска нужно проверить реальные результаты обоих заданий, их связь с
commit в GitHub и расход бесплатных кредитов. Только затем переносить backend,
frontend, desktop, audit, E2E, production/recovery и финальную проверку полноты
отчётов. Короткий пилот нельзя назначать обязательным контролем вместо полного CI.

Месячные лимиты и доступность ресурсов проверяются в Plan / Overview и Usage
самого аккаунта. Бесплатные кредиты не равны минутам: Windows и Linux расходуют
их с разной скоростью. При запросе карты или перехода на платный план остановить
настройку, а не подтверждать покупку.

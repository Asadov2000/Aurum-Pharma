# Aurum Pharma: утверждённый логотип 12.8

`12-8/` содержит общие векторные исходники для приложения и публичного сайта.
Пользователь выбрал 12.8 и отдельно разрешил внедрение. Варианты 12.1–12.7
были промежуточными макетами; runtime-ресурсы не должны ссылаться на `.codex/`.

Надпись Segoe UI Semibold переведена в кривые. Файлы шрифта не распространяются,
для отображения SVG шрифт не требуется. Цвета: #00566B, #079D9A, #11313D.
На тёмной поверхности используется белая версия. Для favicon — упрощённый знак.

Обновить копии и PNG существующим Chromium из frontend Playwright:

```sh
node scripts/build-brand-assets.mjs --png
```

Проверить совпадение SVG с исходниками и размеры PNG без браузера:

```sh
node scripts/build-brand-assets.mjs --check
```

`icon-maskable.svg` имеет непрозрачный квадратный фон и уменьшенный знак
в центральной безопасной области. PNG 192/512 — обычные PWA-иконки,
PNG 180 — Apple Touch. При следующей смене бренда обновлять версию URL
иконок в manifest/index/BrandMark и версию статического кэша service worker.
Адрес самого manifest и `id: "/"` оставлять стабильными: они связывают обновление
с уже установленным приложением. Текущий href `/manifest.webmanifest?v=12-8`
сохранён для совместимости; его query не является версией будущих выпусков.

Service worker проверяет manifest по сети с повторной HTTP-валидацией и использует
последнюю успешную копию при кратковременном сбое. Это обновляет метаданные,
доступные браузеру, но не гарантирует замену установленного ярлыка Windows.
В [Chrome 144+](https://developer.chrome.com/blog/improvements-to-web-app-updates)
существенная смена логотипа требует подтверждения через меню обновления приложения;
у Яндекс Браузера и других браузеров поведение может отличаться.
Нельзя показывать «иконка обновлена» только по версии сайта или ответу системного
API. Проверять нужно также фактический ярлык. Управление ярлыками при обновлении
будущего Windows-клиента относится к его установщику, а не к JavaScript сайта.

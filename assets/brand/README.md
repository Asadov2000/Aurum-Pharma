# Aurum Pharma: утверждённый логотип 12.8

`12-8/` содержит общие векторные исходники для приложения и публичного сайта.
Пользователь выбрал 12.8 и отдельно разрешил внедрение. Варианты 12.1–12.7
были промежуточными макетами; runtime-ресурсы не должны ссылаться на `.codex/`.

Надпись Segoe UI Semibold переведена в кривые. Файлы шрифта не распространяются,
для отображения SVG шрифт не требуется. Цвета: #00566B, #079D9A, #11313D.
На тёмной поверхности используется белая версия. Для favicon — упрощённый знак.

Обновить копии и PNG существующим Chromium из frontend Playwright:

```sh
node scripts/build-brand-assets.mjs --png
```

Проверить совпадение SVG с исходниками и размеры PNG без браузера:

```sh
node scripts/build-brand-assets.mjs --check
```

`icon-maskable.svg` имеет непрозрачный квадратный фон и уменьшенный знак
в центральной безопасной области. PNG 192/512 — обычные PWA-иконки,
PNG 180 — Apple Touch. При следующей смене бренда обновлять версию URL
в manifest/index/BrandMark и версию статического кэша service worker.

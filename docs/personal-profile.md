# Личный профиль

Страница `/profile` доступна каждому вошедшему пользователю из аватара/имени
в шапке и раздела «Мой аккаунт» в настройках, включая сотрудников без прав
управления ролями и сотрудников Aurum без выбранной аптеки.

`GET /api/v1/auth/profile` возвращает только текущего пользователя. Клиент
не выбирает чужой `user_id` или организацию. Названия назначенных ролей и точек
читаются через обычную RLS-сессию из уже разрешённых действующих назначений;
неактивные членства, роли и точки не отображаются. Назначение для всей аптеки
отличается от назначения в отдельной точке. Ответ имеет `Cache-Control: no-store`.

Список предназначен для отображения, а не для принятия решений о доступе.
Источником разрешений остаётся серверная авторизация. В контексте поддержки
профиль показывает личность сотрудника Aurum, без фиктивных ролей сотрудника
аптеки. Выбранная область поддержки остаётся в отдельном существующем баннере.

Официальное ФИО доступно только для чтения: рабочие документы используют его,
поэтому самостоятельное редактирование здесь не добавлено. Подтверждение и
смена номера, создание пароля и дополнительные средства защиты используют
существующие механизмы аккаунта. Старые ссылки безопасности сохраняются.

Страница загружается отдельно от старта кассы. Её кеш привязан к пользователю
и текущей организации; при повторном открытии данные обновляются. Ошибка
обновления не выдаёт прежний список назначений за актуальный.

[Собственные кассовые смены](my-work-shifts.md) доступны в «Моя работа».
[Ручные сведения о зарплате и выдачах наличными](manual-staff-pay.md) доступны
сотруднику в том же разделе после нажатия «Показать сведения».
Автоматическое начисление не добавляется.

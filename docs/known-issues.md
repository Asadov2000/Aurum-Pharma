# Known Issues

Файл для фиксации известных проблем, временных обходов и техдолга. Источник истины
по поведению системы — реальный код; этот список нужен, чтобы не терять
отклонения между задачами.

Полный снимок состояния и порядок работ находятся в
[`development-state.md`](development-state.md).

## Открытые проблемы

1. **P0:** до production нет проверенного backup/WAL/PITR и restore drill для
   PostgreSQL, а также versioning/off-site восстановления для MinIO.
2. **P0:** внутренние соединения с PostgreSQL, Redis и MinIO еще не переведены
   на production TLS.
3. **P0:** PR `#75` с production hardening нужно актуализировать относительно
   `main`, полностью проверить и только затем сливать.
4. **P1:** Playwright POS-сценарий со сканером иногда не получает ответ
   `catalog/by-barcode` за 15 секунд; retry проходит.
5. **P1:** повторный полный backend-прогон на уже использованной тестовой БД
   может встретить остаточное MFA-состояние. Чистая одноразовая БД проходит все
   895 тестов.
6. **P1:** импорту каталога нужны явные resource limits для защиты от больших и
   специально подготовленных файлов.
7. **P1:** JWT-контракту нужны обязательные `iss`, `aud`, `typ` и `jti` с
   совместимым планом перехода.

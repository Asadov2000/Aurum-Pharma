# Проверяемое исправление braces 3.0.3

Дата решения: 03.10.2026. Пересмотреть до 03.11.2026; после этой даты CI
автоматически блокирует временное решение.

`GHSA-vfj7-8cjw-p6xm` затрагивает рекурсивную обработку вложенных шаблонов.
Исправленного npm-релиза пока нет. Пакет используется только сборочными
зависимостями Tailwind 3.4: chokidar и micromatch, включая путь через fast-glob.
Tailwind 3 сохраняется ради совместимости приложения со старыми браузерами.

В `frontend/patches/braces@3.0.3.patch` перенесена защита глубины из
[upstream PR #72](https://github.com/micromatch/braces/pull/72), коммит
`d0d575e55e74a4e0218e5248fafb79efc3e54ebb`. Ограничение фиксировано на 100 уровнях
для parser и всех трёх обработчиков AST. Параметр `maxDepth` не добавляется.
Передача parent в stringify сохранена как в 3.0.3, чтобы не изменить escapeInvalid.

Аудит продолжает показывать advisory по номеру версии. Поэтому CI учитывает
ровно эту advisory только при одновременном выполнении условий:

- Версия и все пути зависимости соответствуют проверенным сборочным цепочкам.
- SHA-256 всех пяти исправленных файлов фактически загруженных пакетов совпадает.
- Регрессионные проверки подтверждают отказ на чрезмерной вложенности строк и
  напрямую переданных AST, а обычные шаблоны, диапазоны и escapeInvalid работают.
- Срок пересмотра не истёк. Неполный отчёт или недоступный аудит блокируют CI.

Остальные high/critical advisory блокируются как прежде. Новая advisory для
braces тоже блокируется. Полный отчёт сохраняет сведения об остальных уровнях;
порог CI остаётся high.

Проверить локально из frontend:
`node --test scripts/audit-dependencies.test.mjs` и
`node scripts/audit-dependencies.mjs`.

После выхода исправленного релиза: обновить пакет, удалить patch и ветку
обработки этой advisory в аудиторе; сохранить проверки отказа на опасных входах.
Не продлевать срок без повторной проверки upstream и установленных зависимостей.

Источники: [advisory](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm),
[требования браузеров Tailwind](https://tailwindcss.com/docs/upgrade-guide).

# Верхняя панель рабочей области

Принят вариант 03 «Быстрые переходы». Панель одинакова во всех рабочих разделах;
реализация: `components/layout/AppHeader.tsx`, подключение: `AppLayout.tsx`.

- Первая строка: контекст рабочей области, поиск разделов, соединение,
  уведомления и меню профиля. Существующее название контекста поддержки берётся
  из текущей сессии; вымышленные названия аптек и точек из макета не используются.
- Вторая строка: избранные разделы из существующих настроек меню. При отсутствии
  доступного избранного показываются основные рабочие переходы. Скрытые пункты
  и пункты без разрешения не появляются. Длинный список прокручивается внутри
  строки, не расширяя страницу.
- Поиск открывается кнопкой или Ctrl+K / Cmd+K и использует ту же разрешённую
  навигацию. Выбор раздела повторно проверяется в текущем списке доступа.
  Поиск не обращается к товарам, пациентам или сотрудникам.
- Меню профиля: личный профиль, своя работа при наличии доступа, безопасность,
  уведомления, настройки, фактический режим запуска и установка PWA, если она
  доступна. Выход отделён от навигации. Email не выводится в верхней панели.
- Соединение использует существующий `ConnectivityContext` и его повторную
  проверку. Статус сети не подтверждает синхронизацию и не разрешает автономные
  операции. Правила доступа и поведения без интернета остаются в существующих
  механизмах приложения.

Высота обеих строк входит в `--app-header-height`: боковая панель, касса и
закреплённые карточки учитывают её целиком. Проверки: shell/search Vitest и
`e2e/header-navigation.spec.ts`; общий browser flow остаётся в CI gate.

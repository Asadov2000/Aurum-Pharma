# ADR-0027: Централизованный журнал карантина Edge

- Статус: принят
- Дата: 2026-08-29
- Уточняет: ADR-0001, ADR-0013

## Контекст

Edge останавливает применение событий при разрыве последовательности, конфликте
идентичности или нарушении контрольных сумм. Ранее Cloud не получал точную
причину остановки, а причины без входящего события не сохранялись после
перезапуска worker. Автоматический сброс курсора опасен: он может скрыть потерю
продажи, повторить денежную операцию или нарушить неизменяемый аудит.

## Решение

`sync_quarantine_incident` является неизменяемым техническим журналом. Запись
создаётся на Edge в одной транзакции с остановкой курсора и затем с тем же UUID
идемпотентно отправляется в Cloud. Tenant, branch и node на Cloud берутся из
аутентифицированного `EdgePrincipal`, а не из тела HTTP-запроса. База сверяет
scope и доказательство с локальным inbox/cursor либо с Cloud outbox/stream.

Журнал содержит только идентификаторы протокола, последовательность, безопасный
код причины, состояние курсора, контрольные хеши и время. Payload, товары,
партии, суммы, способы оплаты, чеки, кассир, клиент, пациент, рецепт, закупочные
цены, credential, SQL и stack trace запрещены.

Запись нельзя обновить или удалить. Повтор того же `incident_id` с тем же
`request_hash` возвращает исходный результат; изменённое содержимое получает
конфликт. Открытый инцидент делает активный узел критическим в мониторинге.

## Восстановление

Система не пропускает событие, не двигает курсор, не переписывает checksum и не
повторяет оплату автоматически. Безопасный путь текущего этапа: инженер проверяет
инцидент, администратор с `platform.sync.manage` и недавней аутентификацией
отзывает проблемный shadow-узел существующей подтверждаемой операцией, после чего
выполняется новое доверенное подключение и bootstrap. Исходный инцидент остаётся
в истории.

Edge writer не очищается и не разворачивается повторно этим механизмом. Его
восстановление требует отдельного протокола для непринятых локальных продаж,
mTLS, ключа устройства и защищённого хранилища согласно ADR-0013.

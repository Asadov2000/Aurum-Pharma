# Реестр архитектурных решений

Принятые ADR являются обязательными архитектурными решениями. Их имена файлов и
ссылки после merge считаются стабильными и не переименовываются задним числом.

## Правила

1. Новый ADR получает следующий свободный четырехзначный номер и уникальный slug.
2. Перед добавлением выполняется проверка существующих файлов `docs/adr/*.md`.
3. Замена решения оформляется новым ADR со ссылкой на замененный документ; старый
   файл сохраняется как история.
4. В коде и документации предпочтительна ссылка на полный filename, а не только
   на номер.

## Исторические коллизии

В репозитории до введения реестра появились две пары одинаковых номеров:

- `0019-dedicated-billing-transition-worker.md`;
- `0019-inactive-edge-database-enrollment.md`;
- `0021-encrypted-recovery-baseline.md`;
- `0021-settings-ownership-and-preferences.md`.

Эти файлы не переименовываются, чтобы не ломать историю и существующие ссылки.
Их полный filename является стабильным идентификатором. Следующий новый номер
после `0032-pos-register-tab-lock.md` должен быть `0033`.

# Дизайн-система Aurum Pharma

Единый визуальный язык: спокойный, профессиональный, медицинский, высокий
контраст. В основе — принципы Apple Human Interface Guidelines: ясная иерархия,
точная геометрия, предсказуемые действия и минимум визуального шума. Для
операционных сценариев используются практики Square POS, Loyverse и
современного медицинского ПО.

## Палитра — почему медицинский teal

Primary — **глубокий медицинский teal** (≈`#0e7568` в светлой теме, ≈`#29b6a3`
в тёмной). Почему он, а не дефолтный синий:

- **Дороже и узнаваемее.** Bootstrap-синий — самый заезженный «дешёвый» цвет
  админок; teal сразу читается как продуманный, не из коробки.
- **Медицинский контекст.** Бирюзово-зелёный — цвет аптек/клиник (чистота,
  здоровье, спокойствие), без агрессии красного и без «корпоративной скуки»
  синего.
- **Контраст.** Глубокий teal-700/600 даёт AA-контраст с белым текстом на
  кнопках; в тёмной теме поднимается до teal-500/400 для читаемости на тёмном.

Остальное — нейтрали на холодном slate (воздух, высокий контраст) и
семантические цвета состояний (success зелёный, warning янтарный, danger
красный, info синий) — приглушённые, не кричащие.

## Токены

Источник правды — CSS-переменные в `src/styles/index.css`, значения в виде
HSL-каналов (`H S% L%`), чтобы работали модификаторы прозрачности Tailwind
(`bg-primary/50`). Tailwind мапит семантические имена на `hsl(var(--token))`
в `tailwind.config.ts`.

### Цвета (роли, переключаются темой)

| Класс | Роль |
|---|---|
| `bg-background` | фон страницы |
| `bg-surface` / `bg-surface-raised` | карточки / модалки и поповеры |
| `border-border` / `border-input` | границы / границы инпутов |
| `text-foreground` | основной текст |
| `text-foreground-secondary` | вторичный текст |
| `text-foreground-muted` | приглушённый текст / подписи |
| `bg-primary` / `text-primary-foreground` | primary-заливка / текст на ней |
| `ring-ring` | focus-ring |
| `text-success` `text-warning` `text-danger` `text-info` | базовые семантические |
| `bg-{tone}-subtle` / `text-{tone}-foreground` | мягкий фон + текст бейджей |

Плюс фиксированная teal-рампа `primary-50…950` для прямого использования
(графики, акценты).

### Шкалы

- **Spacing** — стандартная Tailwind-шкала: `1`=4px, `2`=8px, `3`=12px,
  `4`=16px, `6`=24px, `8`=32px, `12`=48px, `16`=64px.
- **Типографика** — локальный системный sans-стек с приоритетом Segoe UI для
  `font-sans` и `font-display`. Внешние font-hosts запрещены: интерфейс не ждёт
  сеть и не меняет метрики после загрузки; размеры `text-xs…text-4xl`, веса
  400/500/600/700, letter-spacing всегда `0`.
  Цифры — **табличные** (`tabular-nums` на `body`): деньги, количества и
  итоги выравниваются в колонки.
- **Радиусы** — `rounded-sm` 6px, `md/lg/xl` 8px. `rounded-full` применяется
  только для индикаторов, бейджей и переключателей.
- **Тени** — только для меню, диалогов и поднятых интерактивных слоёв.
  Рабочие панели и таблицы отделяются границей.
- **Длительности** — `duration-fast` 120ms, `duration-base` 160ms,
  `duration-slow` 200ms. Анимируются только цвет, прозрачность и transform.
- **Z-index** — `z-dropdown` 1000, `z-sticky` 1100, `z-overlay` 1200,
  `z-modal` 1300, `z-popover` 1400, `z-toast` 1500.

### Плотность интерфейса

Общие примитивы поддерживают три режима через `data-density` на `<html>`:

- **Компактно** — больше строк и данных на экране для мыши и клавиатуры.
- **Обычно** — основной сбалансированный режим.
- **Сенсор** — цели нажатия от 44px, увеличенные поля и строки таблиц.

Выбор доступен в меню «Вид интерфейса» в шапке и хранится локально под ключом
`ui:density`. Сохраняется только одно значение из фиксированного списка, без
данных пользователя, аптеки или фильтров. Тема и плотность применяются до
первого рендера через `public/theme-init.js`, поэтому интерфейс не скачет при
загрузке.

## Тёмная тема

- Тумблер (Светлая / Тёмная / Системная) находится в меню «Вид интерфейса»
  в шапке приложения.
- Выбор сохраняется в `localStorage` под ключом `theme:preference`.
- Применяется через атрибут `data-theme` на `<html>`; «системная» читает
  `prefers-color-scheme` и слушает его изменения.
- Инлайн-скрипт в `index.html` ставит тему **до первого рендера** —
  нет вспышки неправильной темы. Логика — в `src/lib/theme.ts`.
- Переключение мгновенное: меняются только значения CSS-переменных.

## Примитивы

Все примитивы в `src/components/ui/` используют **только токены** — поэтому
работают в обеих темах автоматически. Доступные: `Button` (variants
primary/secondary/ghost/danger; sizes sm/md/lg/**xl** — большой touch-таргет
для POS), `Input`, `Select`, `Textarea`, `Label`, `Card`, `Badge` (5 тонов),
`Switch`, `Modal`, `Table` (+ `TableEmpty` с `title`/`icon`/`action`),
`FormError`, `Skeleton` / `SkeletonRows`, `PageHeader`, `Checkbox`,
`SegmentedControl`, `ConfigurableFilterBar`.

Focus-ring задаётся глобально через `:focus-visible` в `index.css` — виден
с клавиатуры, не появляется при клике мышью (a11y).

## Правила

- Не хардкодить цвета/отступы в компонентах — только токены/шкалы.
- Загрузка списков — `SkeletonRows`, не «Загрузка…».
- Пустые состояния — дружелюбные, с действием («Добавьте первую позицию» +
  кнопка), не «Нет данных».
- Верх страницы всегда оформляется через адаптивный `PageHeader`.
- Карточки применяются для повторяющихся объектов, модальных окон и
  самостоятельных инструментов. Секции страницы не вкладываются в карточки.
- Рабочие поверхности используют тонкую границу и радиус не более 8px.
- Панели списков используют `ConfigurableFilterBar`: значения фильтров принадлежат
  разделу, а локально сохраняется только состав видимых полей. Полный контракт
  описан в `docs/configurable-filters.md`.
- Внешние шрифты, blur, постоянные pulse-анимации и тяжёлые фоновые эффекты
  запрещены. Это сохраняет быструю работу на слабых ПК и при нестабильном
  интернете.
- При `prefers-reduced-motion` переходы и анимации практически отключаются.
